# PuertaSinLlave.com — Guía en Español de Cerraduras Digitales para Casas, Departamentos y Alquileres Temporales

Portal editorial y comparativo construido con **Next.js 16 App Router (100 % SSG estático)**, motor dual de afiliados Amazon (`puertasinllave-20` en Amazon EE. UU. y `puertasinllave-21` en Amazon España), verificador interactivo de medidas de puerta (`/verificador-de-medidas/`) y Asesor Técnico IA conectado a Supabase (`charlielingan`).

- **Titular:** CARLOS LINGAN BORJA — Lima, Perú (`info@charlielingan.com`)
- **Arquitectura SEO:** 14 Hubs Pilares + 520 Artículos Transaccionales + 1,000 Artículos SEO Informacionales = 1,543 páginas estáticas sin canibalización.
- **Imágenes:** Generadas vía ChatGPT Image API (`gpt-image-1`, `quality: "medium"`) en Supabase y optimizadas en WebP `< 100 KB`.
